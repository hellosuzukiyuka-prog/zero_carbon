# ゼロカーボン大作戦：潜在層の参加ニーズ・情報源分析

## 目的と対象
「内容によっては参加したい」と回答した人を「潜在層」と定義し、回遊促進施策と広報施策の具体化に役立てる。これは環境関心の低い層を直接識別したものではない。

使用データ：（作業用2.2）アンバサダー2026-10-16時点データ.xlsx のコピー.xlsx のコピー.xlsx - シート2.csv。前版の「学生かどうか判別できない」という記述を、職業欄を用いた集計に更新した。企画・情報源・年代・参加意向の回答内容は前データと一致するため、従来のランキングは変わらない。

有効回答674人のうち潜在層は472人（70.0%）。元CSVの末尾にある参加意向空欄の1行は除外した。

## 活動・企業共有への活用案

- 回遊施策：少数ブースでも完了できるコース、個人参加、短時間の体験、特典を検討する。
- 広報施策：情報源上位の媒体を中心に、体験時間・参加方法・内容を具体的に告知する。
- 出展企業との共有：短時間・1人でも参加しやすい体験と、暮らしにつながる説明を提案する。集計結果と提案を区別して伝える。
- 実施後：参加者年代、来場のきっかけ、回遊ブース数、体験の感想を確認し、施策を評価する。

## 集計の注意点

選択率は各項目の選択人数÷潜在層472人。複数回答なので合計は100%を超える。

「最大3つ選択」の企画設問に4つ以上選んだ回答が潜在層で112件ある。主集計では保持し、Excelに3つ以内の回答者360人に限った参考集計を収録した。元フォームや転記方法の確認が必要で、参考集計も正解とみなすものではない。

環境配慮行動の実施状況や心理的ハードルは本CSVでは直接分析できない。実際の参加や行動変容の因果効果はこの集計からは判断できない。
