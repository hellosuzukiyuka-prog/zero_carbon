「内容によっては参加したい」472人を潜在層とし、積極層85人・消極層117人と比較。環境への関心の高低とは別の区分です。

年代別の潜在層割合に明確な差は検出しませんでしたが、潜在層の情報源や複数の行動には年代差があるため、年齢を一律には無視しません。未補正pとBH補正q、関連の大きさ、実際の割合を区別します。

## 再実行

必要パッケージ：pandas、numpy、scipy（MonteCarloMethod対応版）、statsmodels、patsy、openpyxl、python-docx、reportlab、matplotlib。実行時のバージョンは `解析メタデータ.json` に記載。

```bash
python analyze_profile.py "元CSVのパス"
python create_report.py
```

元データは回答ID・時刻・自由記述を含むため、このリポジトリには保存していません。レポート生成の図表にはNoto Sans CJK日本語フォントを使用。HTMLは図のPNGと同じフォルダーで開いてください。

個別の自由記述は今回の分析対象外。主分析は選択式回答の探索的な比較です。元Q9の単一回答と実際の複数回答、元Q10-2の3項目指定と実際の選択数に不一致があることを、レポートとExcelに記載しています。
